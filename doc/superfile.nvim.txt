*superfile.nvim.txt*   superfile file manager in a floating window

==============================================================================
CONTENTS                                              *superfile.nvim*

Open superfile (https://github.com/yorukot/superfile) in a floating terminal
and open the files you pick in Neovim.

==============================================================================
COMMANDS                                              *:Superfile*

:Superfile              Open at the current file (cursor lands on it). With
                        `resume = true`, brings back a hidden superfile.
:Superfile toggle       Show or hide superfile, keeping its place.
:Superfile cwd          Open at Neovim's current working directory.
:Superfile {path}       Open at {path} (always starts fresh).

==============================================================================
KEYS (inside superfile)                               *superfile-keys*

Enter / l / e           Open the focused file in Neovim with |:edit|.
<C-o>v                  Open in a vertical split.
<C-o>s                  Open in a horizontal split.
<C-o>t                  Open in a new tab.
<C-o>g                  Live grep in the focused folder (or the folder
                        containing the focused file).
<C-o>f                  Find files in that folder.
<C-o>y                  Copy the path, relative to Neovim's cwd.
<C-o>Y                  Copy the absolute path.
<C-o>h                  Hide superfile (only with `resume = true`).
{toggle_key}            Hide superfile, or quit it if `resume = false`.
q                       Quit superfile.

The <C-o> keys work on folders as well as files.

==============================================================================
SETUP                                                 *superfile.setup()*

>lua
    require("superfile").setup({
      cmd = nil,
      args = {},
      open_for_directories = false,
      change_neovim_cwd_on_close = false,
      on_directory_chosen = "edit",   -- "edit" | "cd" | "ignore"
      resume = false,
      toggle_key = nil,               -- e.g. "<C-g>"
      deleted_buffers = "ask",        -- "ask" | "wipe" | "ignore"
      copy_registers = { "+", '"' },
      floating_window = { width = 0.9, height = 0.9, border = "rounded" },
      keymaps = {
        open_in_vsplit = "<C-o>v",
        open_in_split = "<C-o>s",
        open_in_tab = "<C-o>t",
        grep_in_directory = "<C-o>g",
        find_in_directory = "<C-o>f",
        copy_relative_path = "<C-o>y",
        copy_absolute_path = "<C-o>Y",
        hide = "<C-o>h",
      },
      superfile_choose_key = "e",
      integrations = { grep_in_directory = nil, find_in_directory = nil },
      on_file_chosen = nil,           -- fun(path, action): boolean
    })
<
                                                      *superfile-resume*
By default every |:Superfile| starts fresh, and clicking another window quits
superfile. With `resume = true`, clicking away or pressing <C-o>h hides it
instead, and the next |:Superfile| brings it back where you left it.

`toggle_key` is one key that opens or resumes superfile in normal mode and
hides it from inside superfile. Use a non-printable key such as <C-g>. A key
like "-" can't be typed in superfile's search or rename prompts.

See README.md for details on each option. Run |:checkhealth| superfile
to check your setup.

==============================================================================
LUA API                                               *superfile-api*

require("superfile").open({path})     Open at {path} (default: current file).
require("superfile").open_cwd()       Open at the cwd.
require("superfile").toggle()         Show/hide, keeping superfile's place.
require("superfile").stop()           Stop superfile, hidden or not.
